
# Guida Utente Breve

1. **Apri PowerShell** nella cartella del progetto.

2. **Avvia la GUI** con:
	```powershell
	./GestioneFoto.ps1
	```

3. **Seleziona o crea un profilo** (puoi modificare cartelle, estensioni, filtri, destinazione e database).

4. **Premi `Scansione`** per analizzare le cartelle sorgenti e aggiornare il database con i nuovi file trovati.

5. **Premi `Visualizza`** per visualizzare i  file trovati e il loro stato.

6. **Premi `Copia`** per copiare solo i nuovi file nella cartella di destinazione.

7. **Premi `Esci`** per chiudere il programma.

**Nota:** Tutte le operazioni mostrano log e avanzamento nella finestra principale.
