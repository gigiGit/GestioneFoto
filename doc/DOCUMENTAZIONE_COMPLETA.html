Documentazione Completa - GestioneFoto.ps1

1. Obiettivo

GestioneFoto.ps1 fornisce una GUI per la gestione di foto/video in ambiente Windows PowerShell, con queste funzionalità reali:

  • Caricamento configurazione e profilo (cartelle, estensioni, filtri, destinazione, database)
  • Interfaccia grafica con selettore profilo, parametri configurabili, log, barra di avanzamento
  • Flusso operativo: Scansione, Visualizza, Copia, Esci
  • Logging dettagliato e feedback visivo

2. Architettura

  • Entry point: GestioneFoto.ps1 (GUI WinForms principale)
  • Moduli caricati: lib/log.ps1, lib/config.ps1, lib/wrapper.ps1, lib/gui.ps1

3. Configurazione

  • Configurazione generale: config/config.properties
  • Profili: config/<nome>.profile

Chiavi profilo usate dalla GUI: - ProfileName, MinSize, UserName, IncludePath, ExcludePaths, Extensions, DestinationRoot, DatabasePath, DestinationTemplate

4. Funzionalità GUI implementate

  • Selettore profilo e parametri modificabili
  • Pulsanti: Scansione (aggiorna database), Visualizza (mostra elenco e stato file), Copia (copia solo file “Copiabile”), Esci
  • Log attività e messaggi di stato
  • Barra di avanzamento per operazioni lunghe

5. Flusso operativo reale

  1. Avviare la GUI con ./GestioneFoto.ps1
  2. Selezionare o creare un profilo
  3. Premere Scansione per aggiornare il database con i nuovi file trovati
  4. Premere Visualizza per vedere l’elenco e lo stato dei file
  5. Premere Copia per copiare solo i file marcati come “Copiabile” nella cartella di destinazione
  6. Premere Esci per chiudere il programma

6. Note operative

  • Tutte le operazioni mostrano log e avanzamento nella GUI
  • Target: Windows PowerShell + WinForms
