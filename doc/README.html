GestioneFoto.ps1

GestioneFoto.ps1 avvia la GUI principale per la gestione di foto/video tramite PowerShell e WinForms.

Funzionalità principali

  1. Caricamento configurazione e profilo
    • Legge la configurazione da config/config.properties e dal profilo selezionato (config/<nome>.profile).
    • Imposta parametri di lavoro: cartelle, estensioni, filtri, destinazione, database.
  2. Interfaccia grafica (GUI)
    • Selettore profilo e parametri configurabili.
    • Pulsanti: Scansione, Visualizza, Copia, Esci.
    • Log attività e messaggi di stato.
    • Barra di avanzamento (progress bar) per le operazioni lunghe.
  3. Flusso operativo
    • Scansione: Analizza le cartelle sorgenti, filtra i file secondo i parametri del profilo, aggiorna il database SQLite con i nuovi file trovati (senza duplicati).
    • Visualizza: Mostra l’elenco dei file trovati e lo stato di ciascun record nel database.
    • Copia: Copia fisicamente solo i file marcati come “Copiabile” dal database nella cartella di destinazione, aggiornando lo stato a “Copiato”.
    • Esci: Chiude l’applicazione.
  4. Logging e feedback
    • Tutte le operazioni scrivono log dettagliati nella GUI.
    • La progress bar e le etichette di stato mostrano l’avanzamento delle operazioni.

Avvio rapido

./GestioneFoto.ps1

Requisiti

  • Windows PowerShell 5.1+
  • Moduli e librerie nella cartella lib/
